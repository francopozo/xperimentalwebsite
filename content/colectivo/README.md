# Colectivo X-PERIMENTAL

Informacion editorial del colectivo. Estos archivos alimentan el contenido del landing page.

## Archivos

- `manifiesto.md` — Manifiesto fundacional del colectivo.
- `integrantes.md` — Perfiles de cada integrante (bios, fotos, roles).

## Uso

Edita o agrega archivos aqui. El contenido se traslada manualmente a `src/lib/site-content.ts` para reflejarlo en el sitio.
Cuando Sanity este integrado, esta carpeta servira como referencia historica.
