# Direccion Visual de Referencia

## Proposito

Este documento captura una direccion de arte y motion para el proyecto cultural, inspirada en referencias como `kultiveret.com`, pero reinterpretada para construir una identidad propia.

No es una instruccion para copiar un sitio.
Es una guia para mantener coherencia visual, tono editorial y criterio de animacion cuando desarrollemos la parte visual del proyecto.

## Esencia de Marca

El sitio debe sentirse:

- cultural
- curado
- sereno
- editorial
- humano
- refinado
- contemporaneo
- inmersivo

Debe evitar sentirse:

- corporativo generico
- tecnologico frio
- excesivamente comercial
- sobrecargado
- ruidoso
- ostentoso
- turistico convencional

## Idea Rectora

La experiencia visual debe parecer una mezcla entre:

- revista cultural
- archivo curado
- exposicion digital
- sitio institucional boutique

La interfaz no debe comportarse como una landing agresiva orientada a conversion inmediata.
Debe invitar a explorar, contemplar y descubrir.

## Lenguaje Visual

### 1. Composicion

- Priorizar composiciones editoriales antes que bloques tipicos de marketing.
- Usar una reticula flexible con asimetrias controladas.
- Dejar bastante espacio en blanco o espacio respirable.
- Permitir que algunos bloques se sientan como piezas de exhibicion.
- Combinar secciones densas de tipografia con secciones mas visuales.

### 2. Ritmo

- Alternar momentos grandes y silenciosos con momentos de detalle.
- Evitar que todas las secciones tengan el mismo peso visual.
- Crear una lectura pausada, con cambios de escala entre titulares, textos, imagenes y separadores.

### 3. Fotografia e imagen

- Las imagenes deben sentirse seleccionadas, no decorativas.
- Priorizar fotografias con textura, atmosfera, materialidad y valor cultural.
- Evitar bancos de imagen genericos o imagenes excesivamente pulidas estilo publicidad.
- Usar imagenes como piezas curatoriales dentro de la composicion.

## Paleta y Color

### Direccion cromatica

La paleta debe ser sobria, calida y silenciosa.

Base sugerida:

- fondos hueso, marfil, lino, arena o papel
- textos en carbon, espresso, oliva oscuro o marron profundo
- acentos en verde musgo, azul grisaceo, terracota apagado o laton envejecido

### Tokens de referencia utiles

Estos tonos son utiles como punto de partida porque refuerzan bien la direccion cultural y calida:

- `--color-bg`: `#edece2`
- `--color-bg-alt`: `#e6e3d9`
- `--color-text`: `#1d1917`
- `--color-accent`: `#5a8db0`
- `--color-accent-warm`: `#906036`
- `--color-line`: `#bfccd2`
- `--color-white`: `#ffffff`

### Reglas

- Evitar blancos puros y negros puros como tono dominante.
- Evitar negro absoluto; preferir un oscuro calido como `#1d1917`.
- Evitar saturacion alta.
- El contraste debe ser elegante y legible, no agresivo.
- Los acentos deben ser escasos y significativos.

## Tipografia

### Enfoque

La tipografia es un elemento protagonista.
Debe aportar identidad antes que neutralidad.

### Criterios

- Titulares con presencia editorial y ritmo.
- Cuerpo de texto muy legible, con buen interlineado.
- Jerarquias claras, pero no gritadas.
- Permitir titulares partidos en varias lineas para construir composicion.
- Combinar una familia con caracter para display y otra mas discreta para lectura.

### Combinacion tipografica sugerida

Si luego necesitamos una base concreta para prototipar, esta pareja encaja bien con la direccion:

- display: `Epilogue`
- texto y labels: `Switzer`

No es obligatorio usar exactamente estas fuentes, pero si conservar esta logica:

- una display con caracter editorial contemporaneo
- una sans limpia y refinada para lectura

### Detalles finos

- Usar pesos contenidos, principalmente entre `300` y `500`.
- Evitar contrastes bruscos de peso tipografico.
- El tracking puede ser ligeramente ajustado para que el texto se sienta mas refinado y compacto.

### Sensacion buscada

- sofisticacion tranquila
- cultura contemporanea
- precision sin rigidez

### Evitar

- combinaciones tipograficas demasiado tech
- tipografias excesivamente geometricas sin matiz
- titulares pesados tipo startup
- abuso de mayusculas

## Componentes Visuales

### Hero

El hero debe tener una presencia casi curatorial.

Preferencias:

- titular amplio y expresivo
- subtitulo breve y sensible
- composicion partida en varias lineas
- relacion clara entre texto e imagen
- posibilidad de mosaico o collage estructurado

Evitar:

- hero centrado generico con boton enorme
- claims de marketing vacios

### Navegacion

- La navegacion debe sentirse limpia, discreta y elegante.
- Puede vivir como barra minima o menu expandido con transicion cuidada.
- Los estados hover deben ser refinados: lineas, desplazamientos, subrayados, pequeños flips.
- Evitar menus pesados o visualmente toscos.

### Tarjetas o bloques de contenido

- Deben sentirse como fichas curatoriales.
- Usar imagen, titulo, indice o microdetalle cuando tenga sentido.
- Evitar sombra generica y esquinas redondeadas por defecto si no responden al sistema.
- Priorizar recorte, contraste, alineacion y ritmo tipografico por encima de decoracion.

### Elevacion

- El sistema debe sentirse practicamente plano.
- La jerarquia debe construirse con escala, contraste, alineacion y espacio.
- Evitar sombras protagonistas o efectos de profundidad innecesarios.

### Citas, timeline y metadata

- Muy utiles para un proyecto cultural.
- Deben presentarse con sensibilidad editorial.
- Usar lineas finas, guiones, numeracion, marcas de cita y pequenas estructuras de archivo.

## Motion y Animacion

## Principio general

La animacion debe sentirse artesanal, cinematografica y sutil.
No debe intentar impresionar por cantidad, sino por control.

### Patrones recomendados

- reveal de texto por lineas o por palabras
- parallax muy suave en imagenes o separadores
- transiciones de entrada con desplazamientos cortos y opacidad
- subrayados dibujados
- desplazamientos de flechas o iconos en hover
- menus con aparicion tipo curtain, mask o clip
- runners o carruseles lentos solo si aportan valor narrativo

### Reglas de motion

- duraciones medias, no hiper rapidas
- easing suave y natural
- evitar rebotes innecesarios
- evitar animaciones simultaneas en exceso
- cada animacion debe apoyar jerarquia, foco o atmosfera

### Evitar

- parallax agresivo
- efectos ruidosos
- zooms bruscos
- motion de estilo app/gamificado
- microinteracciones demasiado juguetonas

## Interaccion

- La experiencia debe invitar a explorar, no empujar.
- Hover y focus deben sentirse delicados y precisos.
- Los cambios de estado deben ser visibles pero sobrios.
- La interfaz debe responder con calma y claridad.

## Tono de Contenido

El contenido visual y textual debe comunicar:

- sensibilidad cultural
- mirada curatorial
- cercania humana
- profundidad
- atencion al detalle

Evitar:

- lenguaje promocional generico
- exceso de slogans
- tono demasiado institucional o demasiado comercial

## Sistema de UI Recomendado

Cuando implementemos este estilo, conviene pensar el sistema desde estos tokens:

- `surface`: tonos papel, lino, arena
- `text`: carbon, espresso, oliva oscuro
- `accent`: tono cultural contenido, nunca fluorescente
- `border`: lineas finas y sobrias
- `motion`: easing suave y duraciones consistentes
- `spacing`: generoso, editorial
- `radius`: minimo o muy controlado
- `shadow`: casi inexistente o extremadamente sutil

### Base espacial

Como referencia, el sistema puede apoyarse en una escala espaciosa y modular.
No hace falta copiar una reticula matematica exacta, pero si mantener consistencia en escalas de separacion, padding y ritmo vertical.

Regla practica:

- usar pocos tamanos de espaciado
- repetirlos con disciplina
- favorecer respiracion sobre densidad

## Checklist de Validacion

Antes de aprobar una interfaz, revisar:

- Se siente como un proyecto cultural y no como una startup generica.
- La tipografia tiene personalidad real.
- El layout respira.
- La imagen tiene peso curatorial.
- Las animaciones acompañan sin distraer.
- La paleta transmite calidez y sofisticacion.
- La experiencia general invita a quedarse y explorar.

## Traduccion Practica para Futuras Iteraciones

Cuando usemos este documento para disenar o construir vistas, debemos priorizar:

1. titulares editoriales grandes
2. fondos calidos y sobrios
3. composicion asimetrica controlada
4. imagenes tratadas como piezas culturales
5. animaciones sutiles con intencion
6. componentes discretos, nunca plasticos o demasiado UI-kit

## Formula Resumida

Si hubiera que resumir la direccion visual en una sola frase:

`Una experiencia editorial, cultural y contemporanea, con elegancia silenciosa, composicion curada y motion sutil.`
