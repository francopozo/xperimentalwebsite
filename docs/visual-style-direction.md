# Dirección Visual

## Esencia

Cultural, curado, sereno, editorial, humano, refinado, contemporáneo.
La interfaz debe invitar a explorar, no comportarse como una landing agresiva.

## Paleta

| Token | Color |
|---|---|
| `--color-bg` | `#edece2` |
| `--color-bg-alt` | `#e6e3d9` |
| `--color-text` | `#1d1917` |
| `--color-accent` | `#5a8db0` |
| `--color-accent-warm` | `#906036` |
| `--color-line` | `#bfccd2` |

- Evitar blancos/negros puros, saturación alta o contraste agresivo.
- Fondos hueso/lino/papel. Textos carbon/espresso. Acentos escasos y significativos.

## Tipografía

- Display: `Epilogue` (carácter editorial contemporáneo)
- Texto: `Switzer` (sans limpia y refinada)
- Pesos contenidos (300–500), sin contrastes bruscos, tracking ligeramente ajustado.

## Composición y ritmo

- Layout asimétrico controlado, abundante espacio respirable.
- Alternar secciones densas de tipografía con secciones más visuales.
- Imágenes tratadas como piezas curatoriales, no decorativas.
- Evitar sombras protagonistas; jerarquía por escala, contraste y alineación.

## Motion

- Sutil, artesanal, cinematográfico. Easing suave, duraciones medias.
- Reveal de texto por líneas, parallax muy suave, transiciones con opacidad.
- Evitar rebotes, zooms bruscos, motion estilo app/gamificado.

## Resumen

Una experiencia editorial, cultural y contemporánea, con elegancia silenciosa, composición curada y motion sutil.
